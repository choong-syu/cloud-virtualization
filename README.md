2026학년도 2학기 클라우드가상화 수업에서 함께 따라 하는 실습 자료입니다.

| 주차 | 주제 | 실습 자료 |

## 수업에서 사용하는 방법

1. 해당 주차의 **실습 시작하기**를 엽니다.
2. 학생별 전용 Linux VM에 SSH로 접속합니다. 이번 실습은 Bash를 기준으로 합니다.
3. 교수자가 안내하는 명령 번호로 이동합니다. 명령 제목에서 터미널 A/B를 확인합니다.
4. 명령 블록을 하나씩 실행하고, 설명에 따라 출력 결과를 비교합니다.
5. 마지막 정리 단계까지 마칩니다.

실습 안내에 명령, 예상 결과, 관찰할 항목과 문제 해결 방법이 함께 있습니다. GitHub에서 문서를 보면서 진행하므로 Git 설치나 저장소 복제는 필요하지 않습니다.

PID와 namespace 식별값은 환경과 실행 시점에 따라 달라집니다. 예시의 숫자를 입력하지 말고 자신의 출력값을 사용합니다.
