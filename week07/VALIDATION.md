## 실행 중 발견해 수정한 사항

1. **sudo 사전 확인:** 첫 검사에서는 `sudo -v`가 암호를 요구하여 진행을 멈췄습니다. 이후 `sudo -i`와 일반 sudo 명령이 비밀번호 없이 허용됨을 확인했습니다. `sudo -v`만으로 설치 권한이 없다고 판단한 것은 잘못이었습니다. 준비 스크립트는 `sudo -n true`를 먼저 확인하도록 수정했습니다. sudoers 정책은 변경하지 않았습니다.
2. **runc 터미널 마운트:** 최초 shell 설정에서 `/dev/pts/ptmx`가 없어 실행되지 않았습니다. 세 설정에 devpts 마운트를 추가한 뒤 셸 실행과 sleep 생성·실행을 다시 확인했습니다.
3. **Bridge 조회 문법:** `ip -br link type bridge`는 대상 VM에서 오류가 발생했습니다. 최종 문서는 `ip -br link show type bridge`로 수정했고 정상 출력을 확인했습니다.
4. **실행 위치:** sudo -i 후에는 홈이 /root가 되므로, 학생 계정으로 돌아오는 `exit` 안내를 추가했습니다. 본문은 학생 계정에서 필요한 명령에만 sudo를 붙이는 방식으로 유지했습니다.
